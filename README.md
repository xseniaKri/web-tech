# Доставка бизнес-ланчей - Адаптивный лендинг с Bootstrap 5

## Описание проекта

Проект представляет собой современный адаптивный лендинг для компании доставки бизнес-ланчей, созданный с использованием Bootstrap 5. Лендинг полностью соответствует требованиям лабораторной работы №10 и интегрирован с существующей системой заказов.

## Структура проекта

```
web-tech/
├── landing.html          # Новый адаптивный лендинг (Bootstrap 5)
├── index.html            # Главная страница (старая версия)
├── lunch.html            # Страница сборки ланча
├── order.html            # Страница оформления заказа
├── orders.html           # Страница истории заказов
├── style.css             # Основные стили проекта
├── lunch.css             # Стили для страницы ланча
├── order.css             # Стили для страницы заказа
├── orders.css            # Стили для страницы заказов
├── src/                  # Папка с изображениями
├── scripts/              # JavaScript файлы
└── README.md             # Данный файл
```

## Особенности лендинга

### ✅ Выполненные требования

1. **Hero Section** - блок с названием компании, описанием и привлекательным изображением
2. **Блок преимуществ** - перечисление основных особенностей и преимуществ компании
3. **Call-to-Action блок** - призыв к действию с ссылкой на страницу "Собрать ланч"
4. **Контактная форма** - форма обратной связи с валидацией и контактной информацией

### 🎨 Дизайн и стилизация

- **Адаптивная верстка** - корректное отображение на всех устройствах (мобильные, планшеты, десктоп)
- **Bootstrap 5** - использование современного фреймворка для сетки и компонентов
- **Единообразный дизайн** - соответствие существующей цветовой схеме проекта (#9007cf)
- **Интерактивные элементы** - плавные переходы, hover-эффекты, анимации
- **JetBrains Mono** - использование существующего шрифта проекта

### 📱 Адаптивность

Лендинг полностью адаптивен и корректно отображается на:
- **Десктоп** (1200px+)
- **Планшет** (768px - 1199px)
- **Мобильный телефон** (до 767px)


### 🛠 Технологии

- **HTML5** - семантическая разметка
- **Bootstrap 5.3.2** - фреймворк для сетки и компонентов
- **Bootstrap Icons** - иконки для улучшения UI
- **JetBrains Mono** - шрифт проекта
- **JavaScript** - интерактивность и валидация форм

### 🎯 Упрощенная архитектура стилей

- **Только Bootstrap** - используются стандартные утилиты Bootstrap
- **Минимальные кастомные стили** - только шрифт JetBrains Mono
- **Утилитарный подход** - все стили через Bootstrap классы

## Установка и запуск

### Вариант 1: Локальный сервер Python

```bash
# Перейдите в папку проекта
cd /home/xsenia/web-tech

# Запустите локальный сервер
python3 -m http.server 8000

# Откройте в браузере
# http://localhost:8000/landing.html
```

### Вариант 2: Простое открытие файла

Просто откройте файл `landing.html` в любом современном браузере.
